
# CS2 Bhop

A lightweight bhop project for Counter-Strike 2.

## Features

* Simple and lightweight
* Clean configuration
* Easy to set up
* Built with performance in mind

## Requirements

* Windows
* Counter-Strike 2

## Usage

1. Download the latest release.
2. Follow the included setup instructions.
3. Launch the project.
4. Configure the available options.
