# Velocity

> **⚠️ Velocity has been abandoned.**

Hey everyone,

I’ve decided to stop working on Velocity and officially abandon the project.

I started Velocity mostly as a way to learn more about coding and reverse engineering. I learned a lot while working on it, but I’ve reached a point where I’m having trouble fixing some of the issues and keeping the project working.

I’m still learning, and honestly, I don’t have the knowledge right now to properly fix everything that’s broken. Instead of leaving the project in a half-working state and constantly saying I’ll fix it later, I think it’s better to just call it here.

Thanks to everyone who used Velocity, followed the project, reported issues, or gave me feedback. I genuinely appreciate it.

Maybe I’ll come back to it someday, but for now, development is finished.
