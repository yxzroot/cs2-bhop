# CS2 Bhop

A lightweight and simple bhop project for **Counter-Strike 2**.

## Features

* Lightweight and performance-focused
* Clean and simple configuration
* Easy setup
* Minimal interface
* Regular updates and improvements

## Requirements

* Windows
* Counter-Strike 2

## Getting Started

1. Download the **latest release** from the [Releases](../../releases) page.
2. Extract the downloaded files.
3. Follow the included setup instructions.
4. Launch the project.
5. Configure the available options.

> Always make sure you're using the latest version before reporting an issue.

## Support

Having problems?

First, download the newest version and check if the issue still occurs.

If you're still experiencing problems, you can:

* Open an issue on the [GitHub Issues](../../issues) page.
* Contact me on Telegram.

When reporting an issue, please include your Windows version, CS2 version, project version, and a description of what went wrong.

## Status

**In development**

CS2 updates may require changes to the project, so features and behavior can change between releases.
