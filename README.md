# Velocity

> **⚠️ Velocity has been abandoned.**

Hey everyone,

I’ve decided to stop working on Velocity and officially abandon the project.

Velocity started as a small project for me to mess around with coding, reverse engineering, and just figuring things out. I honestly didn’t know that much when I started it, and a lot of the project was me learning as I went.

I’ve learned a lot from working on it, even though there were definitely a lot of things I did wrong along the way. I’ve also spent way more time on this project than I originally expected.

Recently I’ve been running into more and more problems that I don’t really know how to fix yet. I’m still learning reverse engineering and coding, and I’ve reached a point where I feel like I’m spending more time fighting the project than actually making progress.

So instead of constantly saying that I’ll fix it eventually, I’m just going to be honest and call it here.

I’m really thankful to everyone who used Velocity, followed the project, reported bugs, gave feedback, or just supported me while I was working on it. Even if the project didn’t end up exactly how I wanted, it was still a pretty big part of my learning.

Maybe I’ll come back to it someday, but realistically, I probably won’t. There are other things I want to learn and work on now.

Thanks for everything ❤️

**Status:** Abandoned
**Development:** Stopped
